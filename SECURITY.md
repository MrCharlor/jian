# Security Policy

## Supported versions

Security fixes are developed against the latest version of Jian. Older versions may not receive security updates.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/lucasaarch/jian/security/advisories/new). If that channel is unavailable, contact [@lucasaarch](https://github.com/lucasaarch) privately on GitHub.

**Do not open a public issue or include secrets, credentials, or personal data in a report.**

Include, when safe:

- The affected version, commit, or deployment image.
- A clear description of the impact and attack prerequisites.
- Reproduction steps or a minimal proof of concept.
- Relevant logs with secrets and personal data removed.
- Any suggested mitigation.

We will acknowledge reports as soon as practical, investigate them, and coordinate disclosure with the reporter. Please do not publicly disclose a vulnerability until a fix or mitigation is available and a coordinated disclosure date has been agreed.

## Scope

This policy covers the Jian repository, its published container image, and the software maintained here. For vulnerabilities in third-party dependencies, report through the dependency's own security process as well and include the advisory reference when notifying Jian.
