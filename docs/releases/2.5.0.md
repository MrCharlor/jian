### Features

* **agents:** the built-in `jev-judgment` skill explains when and how to use the `ask_jev` tool for narrow relevance, choice, evidence and confidence judgments, without treating Jev as an authority ([79ce3fc](https://github.com/lucasaarch/jian/commit/79ce3fc0e5a1d6748e24f82a87e649d9e7c0de7))
* **agents:** `ask_jev` exposes bounded yes/no, choice and score judgments with small state limits and a safe fallback when Jev is unavailable ([79ce3fc](https://github.com/lucasaarch/jian/commit/79ce3fc0e5a1d6748e24f82a87e649d9e7c0de7))
* **openai:** OpenAI and Codex requests receive a stable per-profile, per-model prompt-cache key, preserving reusable prompt prefixes and reducing repeated input costs ([c682311](https://github.com/lucasaarch/jian/commit/c682311c9fb759aa70fc8d377550bb98e5bdc96a))

### Bug Fixes

* **agents:** missing Jev service configuration now has explicit coverage and continues with the fixed behavior ([7df639c](https://github.com/lucasaarch/jian/commit/7df639c4b0bd29a61c4525520e96d9acffd1aafd))

### Upgrading

No migration is required. Jev remains optional; without a TypeSafe key, the gateway keeps its fixed behavior. OpenAI prompt caching is automatic for supported models and endpoints.
